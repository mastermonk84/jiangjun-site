# Jiangjun 将军 — Support

**Jiangjun 将军: Xiangqi Roguelike** is a single-player roguelite built on
strict Xiangqi (Chinese Chess) for iPhone and iPad. March a small,
persistent army of named heroes through nine battles against escalating
classical armies.

## Get help

For questions, bug reports, or feedback about the app, email:

**andrew.ge.wang@gmail.com**

Please include your device model and iOS version if you're reporting a
problem — and the run seed (shown on the war table) if it's about a
specific campaign.

## Frequently asked

**Where is my save?** Campaign progress and the Hall of Fallen Heroes are
stored locally on your device. Deleting the app deletes them — there is no
cloud sync or account.

**Does the app need internet?** No. The game is fully offline.

**Does the app collect any data?** No. See the
[privacy policy](./PRIVACY.md).
